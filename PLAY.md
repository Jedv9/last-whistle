# Last Whistle — how to play (Unity)

Unity 2022.3. Punch Club **systems** (day clock, map hub, click-the-room, automated skill-slot fights). Last Whistle **story and art**. No Punch Club assets, names, or audio.

## Open
1. Unity Hub → open this project (`Unity` 2022.3.62f3)
2. If scenes look stale after a pull: menu **Last Whistle → Build All Scenes**
   - CLI: `Unity -batchmode -nographics -projectPath . -executeMethod LastWhistleSceneBuilder.BuildAllCli`
3. Open `Assets/Scenes/Title.unity` (first in Build Settings) → Play

## Loop (Punch Club navigation)
- **Title → New Game → Bunkhouse 4C** (apartment). Intro tape / Juno missing.
- Click **painted objects** (bag, fridge, cot, TV, tape). You walk there, then the action spends time.
- Door / left **Map** icon → harbor map. Click **buildings** (travel costs minutes).
- Left rail: **Profile / Fight / Map / Skills / Journal** — same chrome as the reference shots.
- Top bar: four vitals, STR / AGI / STA, skill points, cash, day.

## Locations
Bunkhouse, Docks, Union Canteen, Rust Bucket Gym, Bin Alley, Last Whistle diner, Night Market, Iron Temple, Blue Crane club, Harbor Arena, Pier 9 barge.

## Combat (Punch Club 1 style)
- Alley poster, gym, crane board, or arena card — or the **Fight** icon.
- Green **HP** + yellow **energy** for both fighters.
- **Blue slots**: equip attacks / guards / breathers **between rounds**.
- Bell starts the round. Exchanges are automatic. Skills cost energy; empty energy is punished (extra damage + knockdown).
- Opponent slots and perks are visible. Change loadout when the round ends.
- Skill tree: **Crane** (power), **Slip** (speed), **Galley** (gas). Original Whistle names — not Bear/Tiger/Turtle.

Starter slots: Jab, Guard, Breathe. Spend skill points (fights, spars) to unlock.

## Story
Ren Vale, Bunkhouse 4C, Blackwater Docks. Sibling **Juno** missing six days. Tape, locker, Mae, Oz, Lila, Vargas, Crowe, Quiet Ledger / Pier 9. Journal fills as you poke the world.
