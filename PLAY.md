# Last Whistle — how to play (Unity)

## Open
1. Unity Hub → open `C:\Users\jedi2\Projects\LastWhistle\Unity`
2. Open scene `Assets/Scenes/Title.unity` (or press Play if Title is first in Build Settings)
3. Press Play

## Loop
- Title → New Game → Map
- Travel: Bunkhouse, Gym, Docks, Alley, Arena
- In rooms: click to walk, use Train / Work / Eat / Sleep
- Alley/Gym/Arena: Fight (stance → resolve rounds → purse)
- Talk to Juno marker in bunkhouse

## Note
Vertical Punch Club-like systems with Whistle art/story. Not a finished commercial ship.
